產品介紹 | 生產流程

1. 防鏽底漆
主結構鋼管使用無氣噴漆機上漆，逐次增加單層噴塗厚度，
以暗紅的底漆做為鋼材與面漆的覆著中介，達到防銹的目的。
2.裁剪鋼材
以精密的帶鋸機取代傳統砂輪切斷機，
鋼材以精準的各種角度裁取。
精確的裁角能使鋼管間毫無誤差的接合。
3.合框綁筋
綁筋是為增加混凝土抗裂的能力。
上下平面框使用大量鋼筋以穩固的電焊熔接，
高密度的綁筋間距使框面倍加穩固。
4. 輕質灌漿
以輕質發泡配比取代傳統混凝土中的砂石配比，
環保又兼具隔熱效果。。
5. 立柱焊接
引進CO2半自動電焊機，
取代傳統電焊機對於
焊道張力、滲透力、及填補效率不足等缺點。
綿密的焊道就是結構穩固的保證。
6. 防鏽塗佈
底部噴塗柏油防潮，樑柱噴塗調合漆防鏽，
屋頂塗佈多道彈性塗料防滲水，全方位提高整體結構的耐久性
7. 安裝門窗
擁有各式門窗型、各種玻璃及各色粉體烤漆供給選用。
8. 內外牆板
選用鋼板知名大廠「燁輝」之
鍍55%鋁鋅烤漆鋼板做為外牆板，
後襯之PU發泡層具有基本隔熱效果。
內牆則採PVC覆膜板，
具有防焰、防水、美觀、耐髒、易清潔等優點。
9. 水電配裝
水電材料皆使用國內CNS認證知名品牌。
熱水管件採用彰源#304不銹鋼管。
確保管件線路安全及長久使用。
10.室內裝潢
具備極佳的客製化能力，一切可依業主需求加以製做。
客廳、廚房、浴室、臥房、系統木櫃等……。
您想的到，我們就做的到。
11.清潔作業
盡可能消除施工過程所產生的汙漬及瑕疵，
使物品完好的交付。
12.裝車出貨
載運超尺寸物品，運輸是過程中最困難的一個環節。
因此車趟皆配有助手、專車親送，
將過程中受損害的風險降到最低。
隨車附贈高壓實心磚做簡易離地墊高之用。
13.現場工事
整地農路、舖面灌漿作業、鐵工大門圍籬、
水電管路作業、景觀工程作業等現地工程，
皆可一條龍式統包服務！
